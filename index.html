About Me

My name is Justin and I'm a Computer Science graduate from MacEwan University.

I've always been interested in using programming as a way to build tools for the things I actually care about, rather than just coding for the sake of it. A lot of my projects come from personal interests and everyday problems I want to solve. That includes things like tracking macros and fitness progress, improving gym training, experimenting with fantasy football analytics, and generally finding ways to make decisions more data-driven and less guesswork-based. I like taking something messy or informal and turning it into a structured system that's easier to understand or use.

On the technical side, I focus mainly on full-stack development, but I've also spent time working with machine learning and computer vision in some of my projects. I enjoy building things that sit at the intersection of software engineering and data, especially when there's a clear real-world application behind it.

My of my hobbies that exemplifies this is fantasy football. I've built projects around it to analyze players, compare performance trends, and try to make more informed lineup and draft decisions using data rather than intuition. I find it really interesting because it blends statistics, prediction, and real world unpredictability in a way that makes it both challenging and fun to model.

Additionally, I'm also interested in gaming and game development. I'd like to eventually build my own games, combining programming, systems design, and creativity to create interactive experiences people can actually engage with.

Right now, I'm focused on improving as a developer by building more complete, polished projects and getting better at designing systems that feel clean, useful, and intentional rather than just functional.

Academic Capstone

A computer vision based home workout app that utilized machine learning to analyze and score these workouts. The phone app, developed in Android Studio/Java, allowed users to record a workout and send it to a cloud-hosted Linux Server with a MySQL database. A Python back end on the Linux server analyzed the workouts using the Keras API for Tensorflow and then returned the results to the user.
