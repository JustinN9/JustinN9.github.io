About Me

I'm a Computer Science graduate from MacEwan University with experience building full-stack web applications and data-driven software solutions. I primarily work with Python, JavaScript, Java, and SQL, and have experience with React, Node.js, Flask, and AWS to build and deploy scalable applications.

I enjoy building software that solves real, practical problems. A lot of my work comes from personal interests where I use data and programming to improve decision-making and turn unclear or messy ideas into structured, usable systems. I'm especially interested in full-stack development, backend systems, and applications where data plays a meaningful role.

Outside of my formal experience, I've built projects involving full-stack development, data analysis, and introductory machine learning and computer vision. One of my main focus areas has been fantasy football analytics, where I developed tools to analyze player performance trends and support more informed, data-driven draft and lineup decisions.

I also have a strong interest in game development and systems design, with a long-term goal of building interactive software that combines technical structure with creativity and user experience.

I'm currently seeking full-time software development opportunities where I can contribute to meaningful projects, continue improving my skills in full-stack engineering, and grow within a collaborative team environment.

Academic Capstone

A computer vision based home workout app that utilized machine learning to analyze and score these workouts. The phone app, developed in Android Studio/Java, allowed users to record a workout and send it to a cloud-hosted Linux Server with a MySQL database. A Python back end on the Linux server analyzed the workouts using the Keras API for Tensorflow and then returned the results to the user.
